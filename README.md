## ✨ Overview

NorthPeak Digital is a sleek and responsive agency website designed to showcase digital services, pricing, client testimonials, and a strong call-to-action. The project focuses on delivering a premium user experience with modern animations, clean layouts, and responsive design.

---

## 🌟 Features

- 🎨 Modern and clean UI
- 📱 Fully responsive across devices
- ⚡ Fast performance with Vite
- 💼 Services showcase
- 💰 Pricing section
- 💬 Client testimonials
- 🚀 Call-to-action section
- ✨ Smooth animations and transitions
- 🎯 Optimized user experience

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Uday-Katale/NorthPeak.git
```

### Navigate into the project

```bash
cd NorthPeak
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
